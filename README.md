# Marinara-Translation-Tools
Translation presets, per-chat glossary, optional user-provided setting context, optional incoming-first previous-message context, character voice instructions, AI provider lock, a shared Connection default for new chats, and Korean language defaults for Marinara Engine.

Downloads:
- GitHub Releases

Version 1.3.0 adds an opt-in v2 preset catalog update with a persistent keep-or-replace choice and optional later removal of legacy presets.

Version 1.3.1 keeps all preset-management buttons on one row and confirms preset deletion.

Version 1.3.2 adds optional user-provided translation context for genre-, period-, region-, and setting-appropriate terminology without adding information absent from the source.

Version 1.3.3 places the optional context behind an explicit Other Instructions checkbox.

Version 1.3.4 replaces the Chinese literary/RP v2 prompt and adds English paraphrase, English source-style, and Chinese paraphrase built-in presets.

Version 1.3.5 groups built-in presets by language while preserving prompt content, selections, and custom-preset order.

Version 1.3.6 persists confirmed custom-preset deletion immediately without requiring a separate Save action.

Version 1.3.8 moves complete prompts into task-based files under `prompts/`, loaded through the documented ordered `config.jsPath` array, without changing prompt text or behavior. See README-KO.md for the file map.

Version 1.3.9 updates the previous-context and user-provided-context reference wording without changing application conditions or request logic.
