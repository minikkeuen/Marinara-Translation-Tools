# 자동 번역 지침 전달 수정안

상태: 엔진 수정 승인 전. 엔진 및 실행 중인 Marinara는 변경하지 않음.

## 확인한 원인

- 브라우저 확장은 `/api/translate` 요청을 처리함.
- Engine 2.5.0의 생성 완료 후 자동 번역은 `translateGeneratedMessage()`에서 직접 AI를 호출하므로 확장의 요청 처리기를 거치지 않음.
- 공개 확장 API에는 서버 자동 번역 요청을 수정하는 기능이 없음.
- 생성 요청 스키마에도 자동 번역의 추가 참고 정보를 받는 필드가 없음.

## 제안하는 변경 범위

1. `extensions/Marinara-Translation-Tools/extension.js`: 생성 요청에 해당 채팅의 저장된 단어장·기타 지침·이전 대화 옵션을 요청 단위로 첨부. 채팅 메타데이터를 임시로 덮어쓰지 않음.
2. Engine의 `packages/shared/src/schemas/chat.schema.ts`: 위 참고 정보를 받는 선택 필드 및 입력 제한 추가. 필드가 없으면 기존 동작 유지.
3. Engine의 `packages/server/src/routes/generate.routes.ts`: 검증된 참고 정보를 해당 생성 요청의 자동 번역 작업에 전달.
4. Engine의 `packages/server/src/services/translation.service.ts`: 자동 번역 직전에 단어장·기타 지침을 시스템 프롬프트에 결합하고, 실제 번역 대상 이전의 메시지를 서버 저장소에서 읽어 참고 컨텍스트로 결합. 저장된 Incoming 프롬프트의 대사 지침 유지.

## 유지할 조건

- 확장의 기존 설정 필드·스키마 버전·프리셋 ID 유지.
- AI 번역에만 적용하며 비AI 공급자는 기존 동작 유지.
- 자동 번역은 서버에서 한 번만 실행하며 브라우저 연결 종료 후에도 완료 가능.
- 추가 정보는 해당 요청에만 적용하며 채팅 설정에 복사하지 않음.
- 기존 5,000자 시스템 프롬프트·50,000자 번역 본문 제한 준수.
- 실행 중인 인스턴스의 설치·활성화·업데이트는 하지 않음.

## 승인 후 검증

- 자동 번역의 최종 AI 호출을 모의 공급자로 포착해 네 항목의 실제 포함 여부 확인.
- 옵션 꺼짐·채팅 간 분리·컨텍스트 범위·재생성/스와이프·비AI 요청·기존 수동 번역 검증.
- 확장 회귀검사 및 변경 범위에 맞는 엔진 검사 실행.
- 확장 ZIP과 엔진 변경 내역 제공. 엔진 배포에는 별도 사용자 지시 필요.
